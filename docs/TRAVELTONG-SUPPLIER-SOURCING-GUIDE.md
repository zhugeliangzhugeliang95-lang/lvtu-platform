# 供应商研究与采购核验指引

## 发现

先从文化和旅游部、全国旅游监管服务平台、国家企业信用信息公示系统和地方文旅主管部门检索，再打开企业官网或认证账号。搜索摘要、营销软文、自媒体、个人微信和无来源黄页只能作为线索，不能作为资质证据。

## 主体核验

按法定名称、统一社会信用代码和许可证编号建立去重键。品牌、集团、门店、分公司和直营网点分别记录；“国际旅行社”字样不等于有出境资质。营业执照不等于旅行社业务经营许可证。

## 证据记录

每项关键字段保存来源标题、URL、来源类型、查询日期、可信等级、摘要、是否仍可访问和是否人工复核。不要保存整篇网页，也不要保存无必要的个人信息。来源冲突时保留双方 URL，状态设为 `UNVERIFIED` 或 `CONFLICT`。

## 评分

内部评分满分 100：合规与资质 30、业务匹配 20、目的地覆盖 15、B2B 可能性 15、公开联系渠道 10、证据质量新鲜度 10。评分只用于人工排序，不是认证、销量或合作承诺。

## 联系和发布

只使用企业官方客服电话、商务邮箱、合作表单、官方账号和办公地址。联系结果写入后台；未取得书面合作意愿的机构不能进入 `ACTIVE`，未完成人工核验和内容审核不能公开发布。设置 `VERIFIED`、`ACTIVE` 或 `isPublic=true` 必须二次确认并写审计日志。

## 复核周期

许可证、经营范围和商务联系方式至少每 90 天复核一次；发现过期、处罚、投诉或官网失效时标记风险并暂停发布。任何自动化询价必须另行取得供应商同意，不能从本研究库直接触发。
